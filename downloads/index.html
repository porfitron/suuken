Kinkeda

Be an early tester for Kinkeda on your phone.

iPhone (Beta)

Install the beta through Apple’s TestFlight app.

Open in TestFlight

TestFlight link not published yet. Ask the team for an invite.

  1. Tap Open in TestFlight above (or use the invite link you received).
  2. Install TestFlight from the App Store if you don’t have it.
  3. Accept the invite and tap Install on the Kinkeda beta.
  4. Launch Kinkeda from your home screen or TestFlight.

Download APK
  1. Tap Download APK above.
  2. When prompted, allow your browser to install unknown apps (one-time permission).
  3. Open the downloaded file and tap Install.
  4. Launch Kinkeda from your home screen.

Pre-release build for testers. Uninstall an older test build before installing a new one if needed.

Web app (PWA)

Add to your home screen for a full-screen app with offline play.

iPhone / iPad (Safari)

  1. Open kinkeda.com in Safari (other browsers on iOS cannot install PWAs).
  2. Tap the Share button (□↑) at the bottom of the screen.
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add, then open Kinkeda from your home screen.

Android (Chrome)

  1. Open kinkeda.com in Chrome.
  2. Tap the Install banner if it appears at the bottom of the game, or
  3. Tap the menu (⋮) → Install app or Add to Home screen.
  4. Confirm, then launch Kinkeda from your home screen or app drawer.

The web version updates automatically when you revisit — no manual reinstall needed.
