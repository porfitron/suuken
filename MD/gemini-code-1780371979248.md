# Architecture & Tech Stack

## Tech Stack
- **Framework:** React 18 with TypeScript.[cite: 3]
- **Build Tool:** Vite.[cite: 3]
- **PWA Plugin:** `vite-plugin-pwa` (handles service workers and manifests).[cite: 3]
- **Styling:** Tailwind CSS (for rapid UI development and flex/grid layouts).[cite: 3]
- **State Management:** React Context or Zustand (Zustand preferred for decoupled game loop logic).[cite: 3]

## Directory Structure
```text
src/
 ├── components/
 │    ├── CornerZone.tsx     # The touchable areas at the 4 corners
 │    ├── GameBoard.tsx      # Central UI holding the active guess dial & countdown
 │    └── Controls.tsx       # Buttons to select guesses (0-4)
 ├── store/
 │    └── gameStore.ts       # Zustand store: game state, turns, points, active corners
 ├── hooks/
 │    └── useMultiTouch.ts   # Custom hook binding touchstart/touchend to corners
 ├── App.tsx                 # Main layout wrapper, prevents default browser gestures
 └── main.tsx
```[cite: 3]

## State Management (`gameStore`)
```typescript
interface GameState {
  turn: 'P1' | 'P2';
  phase: 'GUESS' | 'COUNTDOWN' | 'ACTION' | 'RESOLUTION' | 'GAMEOVER';
  activeCorners: {
    p1Left: boolean; p1Right: boolean;
    p2Left: boolean; p2Right: boolean;
  };
  pressedCorners: {
    p1Left: boolean; p1Right: boolean;
    p2Left: boolean; p2Right: boolean;
  };
  currentGuess: number | null;
  winner: 'P1' | 'P2' | null;
  // Actions
  setGuess: (num: number) => void;
  setCornerPressed: (corner: string, isPressed: boolean) => void;
  resolveRound: () => void;
  resetGame: () => void;
}
```[cite: 3]

## Technical Constraints & Considerations
- **Touch Events:** Avoid `onClick` or `onPointerDown`. Use raw `onTouchStart`, `onTouchEnd`, and `onTouchCancel` to handle multi-touch reliably.[cite: 3]
- **Preventing Browser Gestures:** Add `touch-action: none;` to the global CSS body to prevent swipe-to-go-back or pull-to-refresh on mobile browsers.[cite: 3]
- **GitHub Pages Subfolder Hosting:** Because you are deploying to GitHub pages, ensure `vite.config.ts` has `base: '/your-repo-name/'` and the PWA manifest `scope` and `start_url` align with this base path.[cite: 3]
