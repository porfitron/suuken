# Cursor Prompts for Step-by-Step Implementation

Use these prompts sequentially in Cursor's chat or composer to build the app cleanly.[cite: 2]

**Prompt 1: Setup & Initialization**
> "I want to build a React + TypeScript app using Vite. Please provide the terminal commands to initialize the project, install Tailwind CSS, install Zustand for state management, and install `vite-plugin-pwa`. Then, configure the `vite.config.ts` to support basic PWA settings (manifest, icons, registerType: 'autoUpdate'). Because this will be hosted on GitHub Pages, set `base: '/your-repo-name/'` in the config, and ensure the PWA `start_url` and `scope` match."[cite: 2]

**Prompt 2: Global Styles & Strict Layout**
> "Create the global CSS file. I need the app to take up exactly 100vh and 100vw with no scrolling. Add `touch-action: none;` to the body to disable mobile browser gestures. Also, disable text selection across the app using Tailwind classes or CSS."[cite: 2]

**Prompt 3: Zustand Store Setup**
> "Create a Zustand store in `src/store/gameStore.ts`. Implement the state machine outlined here: The game has turns ('P1', 'P2'), phases ('GUESS', 'COUNTDOWN', 'ACTION', 'RESOLUTION'), and tracks which of the 4 corners are still active in the game, and which are currently being pressed. Include functions to submit a guess, toggle a corner press, resolve the round, and reset the game."[cite: 2]

**Prompt 4: Multi-touch Corner Component**
> "Create a `CornerZone.tsx` component. It should take props for its position (e.g., 'top-left', 'bottom-right'), whether it is active in the game, and whether it is currently pressed. Use `onTouchStart`, `onTouchEnd`, and `onTouchCancel` to update the global Zustand store when a user presses or releases the corner. Style it using Tailwind so it sits strictly in the corner of the screen."[cite: 2]

**Prompt 5: Central Game Board & Flow**
> "Create a `GameBoard.tsx` component that sits in the center of the screen. Depending on the `phase` from the Zustand store, it should display:
> - GUESS phase: A row of buttons (0 to total active corners) facing the active player.
> - COUNTDOWN phase: A large 3.. 2.. 1 timer.
> - ACTION phase: A 'GO! Hold Corners' message.
> - RESOLUTION phase: The result of the round (total pressed vs guessed) and a 'Next Turn' button.
> Ensure P2's UI elements are rotated 180 degrees (`rotate-180` in Tailwind) when it's P2's turn, so they can read it from the top of the device."[cite: 2]

**Prompt 6: Main Layout Assembly**
> "Bring it all together in `App.tsx`. Place the 4 `CornerZone` components in their absolute positioned corners. Place the `GameBoard` in the absolute center. Wrap everything in a container that strictly fills the screen."[cite: 2]
