Kinkeda Mobile Preview

Preview Kinkeda inside simulated mobile devices with notches, camera cutouts, status bars, and navigation bars.

Getting started

  • Kinkeda loads automatically from /app/
  • Choose a device from the selector (iPhone 13 Pro is the default)
  • Adjust status bar and navigation bar colors to match Kinkeda's theme
  • Use the settings panel (tune icon) to switch devices or reload a different URL

Good to know

  • Run a local server from the project root (e.g. python3 -m http.server 8080) and open /demo/ — file:// URLs may block the iframe.
  • Devices are defined by viewport size, not physical size. Use the Device scale toggle for approximate real-world sizing.
  • Powered by EdgeSquare (MIT).
